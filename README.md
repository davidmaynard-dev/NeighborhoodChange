The traditional conversion method uses a spatial join in Arcgis to assign a neighborhood and census tract value to each block in the decennial census. A population value for the blocks is then aggregated for each neighborhood and tract combination using a pivot table. The aggregate modifier for additive quantities is the proportion of each tract-neighborhood combination’s population to the census tract’s total population. The weighted average modifier for refined quantities (like median age) is the proportion of each tract-neighborhood combination’s population to the neighborhood’s total population.
